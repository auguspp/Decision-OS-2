# Odds Book：固定快照的领域读取

责任为 [#60](https://github.com/auguspp/Decision-OS-2/issues/60) 的跨公司 Odds 领域读取；正常页面和固定入口由 [#13](https://github.com/auguspp/Decision-OS-2/issues/13) 接续。该入口组合已经保存的研究、条件／概率 Odds 与 Watch 身份，不建立第二研究库、计算引擎、行情采集或人工决定。

用户范围仍是 Full 后 Odds 对应价格，以及 Full 尚未解决而会影响 Odds 的关键问题。Quick 可进入普通研究和 Brief 阅读；Book 中可恢复的历史记录不会因此取得新 Full Watch 的准入资格。持续 Watch 的生产与 Brief 采用沿[现役 Full Watch 合同](full-watch.md)，不是打开 Book 的副作用。

## 一次读取究竟证明什么

Book 提供已经保管对象的类型化目录投影。原 Artifact／Research reader 核验确切字节、身份与引用，目录保留原保存结果的字段和日期，供正常阅读器组合跨公司状态、过滤及导航。

**目录读取不隐式重演每份 Odds 的全部行情或每支 Watch 的全部历史。** 保存时的价格资格、活动状态和结果，与今天是否仍适用分别表达。需要完整重算或历史验证时，使用各行给出的精确原 reader 请求，沿[条件 Odds](conditional-odds.md)、[概率 Odds](probability-odds.md)和[Watch 活动](watch-activity.md)原合同恢复。

| 已核事实 | Book 中的含义 | 没有据此成立的事实 |
| --- | --- | --- |
| 原件字节和保存身份一致 | 能定位这份保存对象 | 研究判断正确、已被人工接受 |
| 原结果内有行情资格 | 保存结果声明的原评价时点和政策 | 今天最新价、当前可交易资格 |
| 保存的条件或概率结果 | 保留两种不同的计算资格及原依据 | 自动补概率、重估价值或滚动期限 |
| 同一研究或规格关联 | 精确对象在选定快照中的关系 | 公司同名即同一版本、历史结果仍是当前结果 |
| 保存的活动／检查字段 | 原记录状态、原检查时点和引用 | 整段历史已经重演、今天已再次检查、通知已送达 |
| 某页没有匹配项 | 本页扫描范围内没有可返回匹配项 | 整个仓库没有 Odds、市场安静或任务未执行 |

领域输出明确区分保管验证、未请求的语义重演和未认证的当前适用性。失败不以较早成功对象替代，不把未知转换为零、false 或空白成功。

## 有界发现与稳定分页

`read-odds-book` 接受一个 JSON 查询。允许字段是 `snapshot`、`cursor`、`limit`、`scan_limit` 和 `research_ref`；没有写权限、公开许可、行情地址、模型参数或调用者判断字段。

- 第一次未指定快照时，选择当次实际 records head；后续查询继续使用返回的确切快照。
- `limit` 默认 4，范围 1–8，控制返回卡片数。
- `scan_limit` 默认 16，范围 1–32，控制本次候选扫描量；有过滤条件时，扫描数量可能大于返回数量。
- `research_ref` 是可选的完整研究引用，用于精确版本过滤；不是公司名称的模糊匹配。
- `cursor` 只定位原 repository、snapshot、扫描位置和原过滤范围。它不授权访问，也不证明调用者读过此前各页。
- 返回扫描范围、候选总数、下一 cursor 及本页覆盖。到达最后一页只表示这次扫描到了末端；从非零 cursor 开始不能据此宣称全量检查完成。

候选发现沿现役保存路径，按固定顺序扫描研究修订、受支持的 Odds／Watch 原件和活动选择。没有反向索引，因此不能只检查当前页便断言某家公司没有 Odds。损坏或不可恢复候选保留为明确失败项；它们限制缺项推断，不因另一对象可读而消失。

候选最多 8,192 个；超过上限终止本次读取。单卡上限 128 KiB，超限时保留该候选的 `not-included` 状态；整页上限 4 MiB。正常宿主的原 8 MiB 报告限制及底层请求预算继续生效。

同一快照下，后来的研究 current、结果或活动不挤入原分页。每次仍核原绑定、可达性和权限；历史 cursor 不缓存授权。

## 版本、关系和时钟

每条导航保留完整原引用，不把原保存 commit 改成今天的 commit。发现时获得的快照引用和对象内部原引用可能有不同 commit；逻辑关联同时检查 repository、path、SHA256，以及原引用可达、相应字节确实在选定快照中存在。只比较路径或公司名不足以建立关系。

研究修订、规格、结果和 Watch 分别保留自身身份。当前研究与历史修订不混为一行“最新判断”；同一规格的多份价格结果也不相互覆盖。页内关系会标明其覆盖限制，供 #13 的正常消费者继续读取剩余页后组合。

估值日、目标日、资本条件日、原价格日及原评价／检查时间按原件保留；正常宿主另记录本次读取起止时间，不能用它刷新原件时钟：

- 旧价格结果的恢复不刷新报价日期或政策。
- 价格变化不会暗改原世界、股数、现金、概率或期限。
- 原条件现值的价格距离不是未来收益。
- 原活动窗口及最后实际检查可以供阅读器提示复核；目录不新建检查、延长窗口或恢复暂停活动。
- 数据快照和保存时间不证明历史当时可知性，不推断 Human 接受或正式 Decision。

原件不足时，页面应呈现具体缺口及原打开请求，不能显示一个没有依据的绿色“当前有效”。

## 正常 CLI 与宿主

使用现役 `decision-os store`，不新增服务或凭据：

```console
decision-os store --binding /approved/readonly-binding.json read-odds-book --input /approved/book-query.json
```

最小查询可为：

```json
{"limit":4,"scan_limit":16}
```

后续将实际返回 cursor 原样放入查询，或使用已返回的确切 snapshot 重新选择页；完整研究过滤引用必须来自真实读取回执。例子中的路径是操作者已获准的文件，不是生产对象或许可证明。

正常 `research-runtime.yml` 同样接受 operation=`read-odds-book` 和该查询作为 payload。沿原 code_sha、主线身份、输入／结果大小限制及只读 job；不提供 submission_id 或 expected_head，不触发 writer 或 reconcile。结果中的精确打开请求继续由现役 read-valuation、read-odds、read-odds-assessment、read-probability-odds、read-odds-watch、活动／历史读取等原入口执行。

本组只交领域读取和正常宿主消费。稳定可发现页面入口、跨页组合、交互过滤、浏览器和移动端使用，仍由 #13 的正常 Book 阅读组交付，不因本组 CLI 成功自动完成。

## 访问、发布和终态

整个读取使用同一原 backend/API 和原请求预算。快照只固定对象选择；原生可见性、绑定、anchor、marker 和可达性仍由原 owner 检查，不以新 reader 重置预算或丢失已观察到的权限变化。

公开 Book 组合输出须具备五项现役发布范围：`reading`、`research`、`sources`、`watch` 和 `market`。价格及市场资格虽为保存时的声明，导出仍需原 `market` 范围。入口和最终释放结果分别核验；调用者字段、Source 文本或成功读取不能自授公开许可。查询输入在最终资格检查、整份报告大小检查及报告保存完成后才释放。组合范围由正常宿主固定，不由查询选择；原生私有读取仍沿原绑定和可见性规则。

原生远端读取的 401/403/404/429、传输／请求预算耗尽、绑定或快照终态、已观察到的可见性反转、必需授权撤销，均终止整次操作。后续成功读取不能清除先前 terminal。单个原件在已核树中缺少配套对象、损坏或格式不符与这些操作级失败分别处理；远端访问拒绝不冒充普通空目录。

所有既有 payload、report、tree、缓存、来源与历史边界保持；目录页的 scan_limit 不是增加底层额度的许可。

## 复用、验证和退出

复用现役 VersionedStore、ResearchArtifacts、原 typed 校验、受信 GitHub 固定读取 scope 和各领域原件打开入口。组合使用标准库，不增加通用索引、数据库、分页服务或外部依赖；现成的存储和有界遍历已覆盖本用途。

专属回归保护同快照分页、多公司／多版本关联、条件／概率区别、坏候选、未遍历范围、原引用快照归属及操作级终态。正常 CLI/runtime 验证只读和组合发布；安装消费接续原 `test_odds_runtime.exercise_installed_odds`，使用唯一 cold wheel 和同一合成 store，不新增安装流程，也不修改 #13 正在整合的共享页面或根安装消费者。

工程测试、正式 Ready/full、实际 main、真实业务记录的正常读取、浏览器产品验收分别留证。合成案例不是新的生产研究或人工接受。

若退出本能力，同一正常 PR 退出专属领域投影、命令与工作流 choice、组合接点、专属测试及本说明；继续保留原 Odds、Watch、Source、Research 和历史 reader。回退代码不删除用户原件、活动或提交日志。
