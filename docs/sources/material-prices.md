# 生产资料价格：真实来源与有限监测

本入口落实最终设计第9章的输入、基线、窗口、发现与失败合同，以及实施基线5.2的第一组商品来源。上一层[产业读取](industry-reading.md)负责确切资料比较和有发行人证据的双向经营角色；此处负责真正取得价格，不把概念标签当公司受益。

## 第一组范围

国家统计局[最新发布](https://www.stats.gov.cn/sj/zxfb/)中的“流通领域重要生产资料市场价格变动情况”。每次只查首页及后两页，取其中最新三个不同统计旬的公告，最多六次请求，无重试、重定向或替代提供商。响应单份最多4MiB，单次网络等待12秒；120秒后不再开始请求。这不是整个下载过程的硬截止时间。

按公告原产品名、规格和单位创建稳定主体。涵盖公告中的黑色/有色金属、化工、油气、煤炭、建材、农产品、农业生产资料和林产品。目标50个产品、当前取得数、相邻期可比数、规则时效内监测数分列；不把目录名称数签成500+。

统计期、公告时钟、实际取得时间分别保存。保留CNY、原计量单位、流通领域调查、含流通费用/利润/税费、原规格、原披露涨跌及独立计算。官网桌面/手机重复表只能完全一致地去重；冲突、未知表形、非正价格、错期或晚于取得的公告拒绝。缺值不补零，不从披露涨幅倒造独立前期价格。

## 规则和证据

`nbs-material-change-v1`只比较同规格/单位/方法的相邻统计旬：

- 单旬独立计算的绝对涨跌幅达到3%，或连续两次同向且两旬累计绝对变化达到3%，生成机械线索；上涨与下跌对称。
- 持续方向单独保留；微小连续变化不自动触发。3%是首个显式筛选规则，不是统计显著性或经济拐点。
- 最新统计期末距检查日不超过20天才在规则时效内；这不是发布日历保证，也不证明已读全站最新公告。
- 全部50个产品取得、可比且请求均成功、不过期、不倒退，才能给出`no-trigger`。其他情况为`partial-or-unavailable`，保留逐请求状态及已取得结果。
- `bootstrap-existing-release`是第一次看见已有披露；随后区分新统计期、同期间数值/口径修订、仅网页变化、未变与倒退。`new_to_capture`不把重复检查叫新事件。首次得到的历史变化也不叫今天发生。

原披露涨幅有舍入，独立计算与它可以略有差异。每条线索带比较期间、方向、数值差、触发原因、公告URL和响应摘要；不产生公司、盈利弹性、研究委托、通知或人工Decision。

## 取得、恢复和既有消费者

```powershell
python -m decision_kernel.interfaces.material_prices_cli collect --out <new-directory>
python -m decision_kernel.interfaces.material_prices_cli read --capture <saved-directory>
python -m decision_kernel.interfaces.material_prices_cli collect --out <next-directory> --predecessor <saved-directory>
```

目录必须新建。保存`capture.json`、实际`response-*.body`、可交现役保管入口的`source-input.json`及三份`dataset-input-*.json`。后继检查先离线恢复确切前次，损坏即停止，不为修复静默重取；每次取得完成也立即从原字节重建核验。CLI仅在显式调用时执行，本入口没有启用常驻时钟。

原响应只保留在调用者目录，不提交工程main。统计局[服务条款](https://www.stats.gov.cn/wzgl/202302/t20230217_1912857.html)允许下载使用统计数据、要求显著注明来源，并对联合署名/他人作品和页面样式等另有限制。本公告含联合署名，不能把数值使用条件解释为全HTML再分发权。公开保管输入仅含注明出处的数值提取、来源摘要和派生结果；不包含网页原件、不授予下游再分发许可。具体公开写入仍用现役`put-source`及原submission/CAS/对账规则，不在本入口另建writer。

`dataset-input`直接采用产业读取器既有CSV列和主体Entity。每份公告作为同一`nbs-material-prices`数据集的不同不可变版本保存，取得各自SourceRef后，用精确行/列选取创建`industry-reading-v1`包。旬末8–11天按完整日历旬比较；规格、地区、单位或方法变化仍拒绝。主体ID直接供有发行人证据的关系包引用，不自动把某产品映射为股票。研究可以引用保存后的数值SourceRef；原HTML未在公开保管时明确标缺，不能宣称原件恢复。

这些专属解析/采集/恢复测试随此来源维护；来源退出时同步退出CLI及专属测试，保留现役共享保管和产业读取能力。

## 仍需接通的原设计范围
